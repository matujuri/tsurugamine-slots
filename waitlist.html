🕖 キャンセル待ちの日を選ぶ

選んだ日の朝 7:00 に、当日のキャンセル待ちを自動で申し込みます

はじめに（この端末で1回だけ）

設定を保存するために、GitHub のトークンをこの端末に登録します。
  1. GitHub でトークンを作る（Fine-grained token）
  2. Repository access は Only select repositories で だけ
  3. Repository permissions の Variables を Read and write に
  4. できたトークンを下に貼り付ける
トークンはこの端末のブラウザにだけ保存され、GitHub 以外には送られません。

日付を選ぶ

平日は押すだけ（18:00 以降の全時限）。土日は押したあと時刻を選びます。月曜は休校日です。

申し込む時刻を選んでください（複数可）

その時刻に始まる時限を申し込みます（9時 = 9:00〜9:59 に始まる時限）。受付の無い時限は申し込まれません。
